# April Chia — Data Science Portfolio

A personal portfolio website built with plain HTML, CSS, and a small amount of JavaScript.

## Site

Once GitHub Pages is enabled, the site will be available at:

https://aprilchia.github.io/portfolio/

## Structure

- `index.html` — portfolio homepage
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation and dynamic footer year
- `projects/ed-to-icu.html` — project overview for the ED-to-ICU escalation modeling capstone
- `.nojekyll` — disables Jekyll processing

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site.

## Customize

Review the content before sharing publicly. In particular, add a preferred contact email, update the skills list to reflect current experience, and add a resume or writing samples when ready.

The ED-to-ICU project page describes an academic, retrospective research project and includes a limitation statement; it is not a clinically validated tool.
